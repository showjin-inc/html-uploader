この見せ方で伝えたいこと

このプロダクトの主役は、最初からAIではありません。
主役は、普段使うチャットです。

  • 通常は、人同士の連絡・共有・相談に使う
  • 必要な時だけ @AI を付けて呼ぶ
  • AIの吹き出しは色と枠を変えて、一目で見分けられる
  • AIが答えられない場合は、人や別ルームに回せる
  • その会話が候補ナレッジになり、あとから整理される
重要：
「AIに質問するための場」ではなく、
「普段のチャットの中にAIがいる」という見せ方にする。
01 / CORE IDEA

面白いのは、日常チャットがナレッジの入口になること。

普通のチャットは、会話して流れて終わります。 ナレッジチャットは、普段のやり取りの中から 残すべき会話だけを拾って、会社の知識に変えていくところが面白いです。

① 日常チャットとして使う

連絡、共有、相談、報告。まずは普段使ってもらえることが前提です。

② 必要な時だけAIを呼ぶ

@AI や #AI を付けて、会話の流れのまま聞けるようにします。

③ 会話が知識として残る

重要なやり取りを候補化し、精査後に正式ナレッジへ育てます。

チャットが先、AIは後。
だから自然に使えて、自然に知識が貯まる。
02 / INPUT

入力は、専用登録ではなく日々の業務から取る。

ナレッジ作りで一番重いのは、最初の入力です。 だから一から登録させるのではなく、普段の業務そのものを入力源にします。

SOURCE 01

日常チャット

連絡、共有、相談、やり取りの中にある判断や注意事項を候補化。

SOURCE 02

現場MTG / 外部打合せ

音声から変更点、注意事項、クライアント特有ルールを抽出。

SOURCE 03

クレーム / 事故 / 失敗

再発防止だけでなく、「何を見るべきか」を知識に変える。

03 / FLOW

チャットからナレッジになるまでのフロー

AIが勝手に全部を正解にするのではなく、最後は人が精査します。 だから現場の知恵を拾いながら、誤情報の固定化を防げます。

1

日常会話

社内チャットの中で、普段どおりに連絡・共有・相談が行われる。

2

AI利用 / 候補化

@AI で呼ばれた内容や、重要な会話をAIが要点整理し、候補ナレッジとして抽出。

3

人が精査

正誤確認、重複整理、適用範囲の判定、古い内容の更新を行う。

4

正式ナレッジ化

検索、AI回答、教育、案件前確認に使える状態で反映され、次回から再利用できる。

候補ナレッジ

まだ確定ではないが、残す価値がある会話。頻出・重要・変更ありを優先的に候補化。

正式ナレッジ

責任者や担当者が確認済みの内容。AI回答や教育用途ではこちらを優先して参照。

04 / KNOWLEDGE LAYERS

「一般論」と「うちのやり方」は分ける。

百合の水揚げ方法のように、世の中の正解が一つではないテーマがあります。 だから、知識のレイヤーを分けて扱う必要があります。

レイヤー 内容 回答時の扱い
共通知識 花・婚礼・ショップ・葬儀など、業界全体で使える一般知識 参考情報として提示
社内標準 ジラフラワーとして正式採用している手順・基準・ルール 原則として優先回答
拠点・チームルール 東京、大宮、福岡、山口、チームごとの差 所属・案件に応じて出し分け
クライアント / 会場ルール 会場・式場・取引先ごとの注意事項、禁止事項、慣習 該当案件では最優先
重要な考え方：
AIが「一般的にはこうです」と答えるだけでは足りません。
「この会社、この会場、この案件ではどうするか」を返せることに価値があります。
05 / WHY THIS WORKS

これは単なる社内Wikipediaではない。

欲しいのは文書保管庫ではなく、 その会社がどう考え、どう判断し、どう動くかが返せる仕組みです。

よくあるナレッジ管理

  • 登録が面倒で続かない
  • 文書だけが増えて更新されない
  • 経験者の判断理由が残りにくい
  • 検索しても「今どうするか」が分かりにくい

ナレッジチャットで目指す状態

  • 日常チャットとして自然に使われる
  • 必要な時だけAIを呼べる
  • 答えがなければ人に回る
  • 会話ベースで会社の判断履歴が残る
06 / EDUCATION & EXPANSION

教育にも、将来の外販にもつながる。

新人教育、ランクアップ確認、案件前の事前確認に使えるだけでなく、 共通知識の部分を整理すれば、社外パートナーや業界向けサービスにも発展できます。

入社時教育

現場用語、品質基準、クレーム事例を対話形式で学べる。

ランクUP確認

実際の事例からケース問題を作り、判断力を見られる。

社外展開

花業界向けの共通知識ベースとして、将来的な外販も可能。

07 / CORE MESSAGE

一番の資産は、文章ではなく判断の履歴。

上手い人が何を見て、
なぜそう判断し、
どう対応したのか。

それが残り続ける会社は、
人が辞めても、知恵まで辞めない。
