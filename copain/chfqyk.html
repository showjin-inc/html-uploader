showcase 集計・レポート機能要件まとめ

作成日:2026年9月8日

1. 背景・目的

月次・年次の実績を昨対比較できる形で把握したい。現状のshowcaseでは応募について応募日・応募媒体を都度記録する仕組みがなく、既存スタッフが再応募した際にどの媒体経由だったかを確認できない状態にある。あわせて、面談・職場見学の実施件数、派遣契約の稼働状況についても同様に集計できる形に整備する。

2. 新設したいログ(イベント単位で記録)

応募・面談・職場見学は、スタッフのプロフィールに1件だけ持たせるのではなく、発生の都度レコードを追加する「ログ」形式に変更する。これにより同一スタッフの複数回の応募・複数社の面談/見学も個別に記録・集計できるようになる。

ログ

主な記録項目

目的・備考

① 応募ログ

応募日 / 応募媒体(自社HP・CO・花JOB・フラワージョブ・Airワーク・Indeed) / 対象スタッフ / 応募先(企業・店舗/依頼) / 雇用区分(エージェント採用・派遣)

現状、応募媒体はスタッフプロフィールに1件のみ保持されており、応募日の記録欄もないため、既存スタッフの再応募時にどの媒体から来たか確認できない。応募の都度レコードを追加するログ形式に変更する。

② 面談実施ログ

面談実施日 / 対象スタッフ / 応募先 / 雇用区分

面談実施件数を月次・年次・昨対で集計するために新設。

③ 職場見学ログ

見学実施日 / 対象スタッフ / 見学先 / 雇用区分

職場見学実施件数を月次・年次・昨対で集計するために新設。

3. 既存項目を活用して追加集計したい指標

契約満了予定日・更新ステータスなど、showcaseに既に存在する項目を用いて以下を集計する。

指標

算出方法・活用データ

派遣スタート件数(新規のみ)

更新を除いた新規契約開始件数。既存項目から月次集計。

派遣更新件数

契約更新ステータスが「更新」となった件数。

派遣契約継続率

分母:その月に契約満了(予定)を迎えた件数 / 分子:そのうち「更新」ステータスになった件数。契約満了予定日・更新ステータスは既存項目を使用。

4. 集計の切り口

  • 期間:月次 / 年次 / 昨対比較(前年同月・前年同期)
  • 応募・面談・職場見学は「エージェント採用」「派遣」の2区分でそれぞれ集計し、合計値もあわせて出す
  • 媒体別・応募先(企業・店舗)別の内訳も参照できるようにする

5. 今後の確認・検討事項

  • 「応募日」の定義(媒体への問い合わせ時点 か showcase入力時点 か)を統一する
  • 再応募スタッフを「新規応募」扱いにするか「復帰」として別カウントするかを決める
  • 応募ログ・面談ログ・職場見学ログを応募先IDで紐付け、応募→面談→職場見学→採用の歩留まり(コンバージョン)も将来的に集計できるようにする
